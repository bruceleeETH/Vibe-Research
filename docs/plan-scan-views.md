# 复盘工作台 · 候选扫描四视角规划

> 状态：待审。确认后按「阶段」顺序开发。
> 口径：延续「不评分、不推荐」——综合排序用**客观多键排序**（无加权总分），
> 复盘视角为**候选 × 入池历史关联**（真实表现回看）。

## 1. 目标

候选扫描当前只有一张成交额降序的表。参照选股工作台的四个视角，把**同一份候选集**做成四种投影：

| 视角 | 回答的问题 | 排序/组织方式 |
|---|---|---|
| 综合排序 | 今天哪些候选最值得先看 | 默认：命中策略数 ↓ → 成交额 ↓；全部列表头可点击排序 |
| 行业视角 | 候选集中在哪些板块 | 按行业分组聚合，组内明细展开 |
| 资金视角 | 主力资金在买谁 | 加主力净额/超大单/净占比列 + 资金条，按主力净额 ↓ |
| 复盘视角 | 之前筛出来的票后来走得怎样 | 只列有复盘池历史的候选，附历次入池 1D/3D/5D/10D |

四个视角共用一次 `/api/review/scan` 响应，前端切换零额外请求。

## 2. 数据层扩展（backend/screener.py）

### 2.1 全市场主力资金快照（新增）

- 源：东财 clist `fid=f62`（与现有快照同一接口族），字段：
  `f62` 主力净额 · `f66` 超大单净额 · `f184` 主力净占比%。
- 复用现有主机探测 + 分页降级 + 0.3s 限流 + 5 分钟缓存（`_clist_page` 泛化出 `fid/fields` 参数即可）。
- join：按 code 并进候选行，取不到时字段为 `null`（资金源对部分 IP 有间歇风控，不能挡住整个扫描）。
- ⚠️ 资金条渲染：条长 = 该票主力净额绝对值 / 当前候选集内最大值（**相对比例，客观呈现**，非评分）。

### 2.2 复盘历史 join（backend/reviewpool.py）

- 新增 `history_by_code(codes) -> {code: [历次入池记录]}`：读本地 reviewpool.json，
  返回每次的 `entry_date / entry_price / perf(d1/d3/d5/d10) / mature / tag`。
- scan 响应给每个候选加 `pool_history`（无历史为 `[]`）。

### 2.3 scan 响应结构（扩展后）

```jsonc
{
  "generated_at": "...", "scanned": 5400,
  "strategies": [...],
  "candidates": [{
    ...现有字段,
    "main_net": -1.2e8,        // 主力净额（元，可 null）
    "super_net": 3.4e7,        // 超大单净额
    "main_pct": -2.1,          // 主力净占比%
    "pool_history": [{ "entry_date": "07-08", "perf": {...}, "mature": true }]
  }]
}
```

## 3. 前端（frontend/src/pages/ReviewPool.tsx）

「候选扫描」tab 内加视角切换条（对齐截图：综合排序 / 行业视角 / 资金视角 / 复盘视角），策略 chips 与过滤条件对四个视角全局生效。

### 3.1 综合排序（默认视角）

- 默认排序：命中策略数 ↓ → 成交额 ↓（客观多键，无总分）。
- **全部数值列表头可点击排序**（涨跌/成交额/换手/量比/PE/主力净额），再点切换升降序。
- 列同现状 + 主力净额。

### 3.2 行业视角

- 按 `industry` 分组；组头聚合：候选数 · 合计成交额 · 平均涨跌幅 · 主力净额合计。
- 组按候选数 ↓ 排（哪个板块筛出的票最密集，客观计数）。
- 组可展开/收起，明细列同综合排序。

### 3.3 资金视角

- 列重排：名称 / 行业 / 主力净额 / 超大单 / 净占比% / 资金条 / 涨跌 / 成交额 / 策略。
- 默认按主力净额 ↓；资金条为集合内相对比例（见 2.1）。
- 资金字段为 null 的候选沉底并显示「—」。

### 3.4 复盘视角

- 只列 `pool_history` 非空的候选（今天又被筛出 & 之前进过池）。
- 每票展开历次入池：入池日 / 入池价 / 1D / 3D / 5D / 10D / 状态 / 当时标签。
- 附客观汇总行：历史入池 n 次 · 成熟 m 次（不算胜率之类的评价性指标，
  原始收益如实列出，怎么解读交给用户/AI）。
- 空态引导：「还没有历史样本——从候选入池，10 个交易日后这里开始有内容」。

### 3.5 AskAI 上下文

各视角把当前投影喂给 AI（行业视角喂分组聚合、复盘视角喂历史表现），suggestions 相应调整（如复盘视角：「哪类策略的历史样本走得更好」）。

## 4. 测试

- 离线：资金 join（含 null 安全）、行业聚合纯函数、pool_history 关联、表头排序键纯函数。
- live：资金快照 shape（`main_net` 字段存在、行数 > 3000）。

## 5. 合规自查

- 无加权总分、无推荐排序：默认排序键（命中数/成交额）公开透明、可被用户改写（点表头）。
- 资金条=集合内相对比例的客观可视化；复盘视角=历史事实回放；均不预测、不评级。
- 「高风险」措辞继续不用，沿用「提示」（客观阈值标注）。
