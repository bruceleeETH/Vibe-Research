# 投资工作台：选择式录入优化方案

状态：第一批功能已实现并验收。2026-09-09。

依据：已通过浏览器读取用户提供的 Investment Playbook 分享页 https://chatgpt.com/s/t_6aa0262c2df481918eeb59230f852051 ，并检查当前 InvestmentWorkbench.tsx 表单。下述交互和验收为本次产品设计，不是原文已经实现的功能。

## 目标

将重复输入变为“选择模板、勾选条件、补充关键参数”。使用当前 React/FastAPI/本地 JSON，不接模型服务、不保留历史版本、不做老格式兼容。用户后续已授权实现，第一批功能已落地。

## 第一批交付

1. 主策略单选：产业趋势、事件驱动、情绪资金。改用可见按钮，初始不预选。
2. 收益来源单选：业绩增长、估值提升、事件催化、情绪溢价、困境反转、周期反转。与主策略分开，始终允许自定义。
3. 主策略联动逻辑、风险、催化候选；每组选项只展示常用项，可展开更多及自定义。只推荐候选，不自动勾选结论。
4. 常见逻辑作为研究假设，例如需求扩张、订单转收入、新产品贡献、利润率改善；选中后补充业务或指标、依据，核验状态仍独立。
5. 入场/退出采用条件列表。第一批仅支持明确语义：入场条件全部满足；任一退出条件触发则进入复查。说明当前系统只记录，不自动监控或执行。
6. 数字条件必须补参数，例如突破价格、收盘跌破所选均线、某日期前订单仍未兑现；空参数标记待补充，不拼成完整计划。
7. 复查提供今天、明天、7天后、自选日期（均为自然日且标注）。不承诺尚未接入日历的“下一交易日”。
8. 从结构化选项生成可复制、只读的计划摘要；自定义补充单独输入，避免摘要与选择项双向编辑后不一致。

## 布局

第一屏“选标的、选策略、选逻辑”：股票名/代码可先手填，主题提供常用与自定义。第二段“计划条件”：入场、退出、下次复查。证据与详细说明折叠，始终显示待核验数量并可展开。

草稿允许缺失；确认时指出未填的个股业务/判断依据、未完成的条件参数，不因模板带有长文本就判定完成。来源等级不等同事实核验状态。默认不设置仓位比例或价格阈值。

## 策略联动示例（候选，不代表事实或交易建议）

| 主策略 | 逻辑候选 | 需要关注的变量 | 失效候选 |
| --- | --- | --- | --- |
| 产业趋势 | 需求扩张、订单兑现、新产品放量 | 业务名称、订单/收入/利润指标 | 客户验证失败、兑现延迟、利润率恶化 |
| 事件驱动 | 订单事件、财报变化、政策/新品事件 | 事件名称、公开时间、受益关系 | 官方否认、事件取消、实际影响不及假设 |
| 情绪资金 | 板块扩散、强势延续、分歧后修复 | 标的角色、板块名称、观察指标 | 龙头走弱、板块转弱、修复失败 |

## 后续再加

- 我的模板：只复用选项结构和习惯，清空证券特定参数、来源、事实状态、日期与确认状态。
- 从持仓/自选自动带入名称和代码。
- 证据来源类别与催化选项扩展。
- 成交/复盘阶段的错误标签。
- 不将 AI 自动写作作为这轮前提。

## 数据建议

新建前后端共用的选项目录（稳定 ID、名称、适用策略、参数要求、摘要格式）。卡片保存选择项 ID、参数和自定义补充。摘要由单一规则生成，不单独维护另一份可编辑逻辑。

切换策略时保留名称、代码与已有证据；不适用的原条件明确标记“需重新确认”，不能静默删除或自动当成新策略条件。

## 验收

- 产业、事件、情绪三种草稿均可主要通过选择完成，不必从空白写长段落。
- 选中逻辑不会自动把证据设为已核实；默认没有买入结论和仓位额度。
- 缺条件参数不能确认，输入完成后摘要准确反映条件语义。
- 自定义可保存；策略切换无静默数据丢失。
- 保存重载后勾选、参数、摘要一致，导出恢复保留结构。
- 与旧表单用同一演示案例比较耗时及输入字符数，以减少重复输入为验收，不预先承诺固定降幅。

## 实施与验收结果

- 共用选项目录：`backend/workbench_catalog.json`，通过 API 提供给前端；前后端统一选项 ID 与参数类型。
- 前端组件：`frontend/src/features/workbench/GuidedEntry.tsx`，摘要只从结构化选择和补充字段生成。
- 自动化：33 项工作台及原交易/复盘回归通过，覆盖无效价格、均线周期、截止日期、缺少依据、策略切换、备份恢复及核验状态不自动升级。
- 浏览器隔离数据验收：新建默认不选策略、策略联动、条件展开、缺参数禁确认、快捷日期、保存后刷新、摘要复制、策略切换保留旧内容及重新确认。
- 现有正式服务选项接口返回 200，真实工作台未写入演示数据。
