# 本地投资工作台 v0.3

已实现：
- 持仓、自选列表增加投资卡入口，仅携带名称、代码；已有卡优先打开，无卡带入草稿待用户保存。
- 复盘统计支持清仓日期范围，按当前策略、本人执行评价分组，显示周期数、胜率、平均盈亏比、毛收益。
- 错误标签分别计次；主要错误对应亏损只计一次。分组与标签可筛选成交周期明细。
- 明确空数据、日期错误、缺失盈亏比、未清仓及不完整历史排除口径。

统计限制：不含费用，不是收益率；当前卡片分类不证明事前计划；本人错误归因不构成因果证据。未完整关联同一投资卡的周期计入未分类。无需旧版兼容，不生成历史快照。

验证：后端回归测试、前端生产构建；隔离演示数据浏览器验证统计显示、明细筛选及同代码打开现有卡片。测试不写真实持仓。

后续：券商文件导入需根据真实脱敏样本确认字段和费用口径，再实现预览、去重和对账。
