# 主题与标的比较

用户授权继续开发。沿用本地 React/FastAPI，不引入行情请求或新数据格式。

## 范围
- 以投资卡现有研究主题分组（去除首尾空白，不自动拆词或合并同义主题），提供未填写主题分组。
- 搜索名称、代码、主题；默认隐藏已撤销卡片，可手动显示。
- 按卡片 ID 选择，最多 4 张，可跨主题，同代码多卡不混淆。筛选不丢失已选项；选择与主题筛选保存在当前页面 URL，返回后保留。
- 并排比较策略、收益来源、关键业务变量、逻辑、判断依据、风险反证、入场/退出条件、复查日期、证据状态与内容。
- 显示缺失字段、未确认策略条件、原策略选项、到期日期；不评分或推荐买卖，不用证据数量推断质量。
- 从比较列打开原卡，保存后返回比较读取最新内容；同代码精确定位。返回保留选择。
- 支持复制文本摘要，用于自己的研究记录，复制失败显示可操作错误。

## 实施与验收
共享投资卡类型与条件格式化，新增比较页、统一导航入口及原卡返回入口。仅 GET 读取现有接口，比较选择不写持仓或工作台记录。
验证前端生产构建、现有后端回归，并以 /tmp 隔离演示数据验证主题筛选、多选上限、缺失内容、证据状态、返回更新和空页面。

## 验收结果
- 49 项现有后端回归通过；前端 TypeScript 与生产构建通过，保留原有包体积告警。
- 隔离演示数据验证：主题筛选保留选择、跨主题比较、未填写主题、四张上限及第五张提示。
- 原卡补充判断依据并保存，返回后四张选择保留且新内容显示；复制摘要成功。
- 比较表验证：参数缺失、原策略选项、策略待确认、证据核验数量、缺失字段均正确显示。已撤销卡片默认排除。
- 投资卡主题字段增加已有主题建议，可自由新建主题。
- 现有本地页面只读验证通过，实际只有一张卡片，新增第二张后可比较；未改真实研究或持仓。
