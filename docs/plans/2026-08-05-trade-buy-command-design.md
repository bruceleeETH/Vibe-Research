# 统一 `trade buy` 命令设计

## 目标

把一次买入报备从多次人工同步压缩为一个本地命令。命令不联网，一次更新：

1. `~/.vibe-research/portfolio.json` 的数量和加权成本；
2. `~/.vibe-research/daily-review/state.json` 的复盘持仓基线；
3. 当日 JSON/Markdown 快照及“当日交易”；
4. 私有 `research/交易台账.md`；
5. `~/.vibe-research/trades.json` 幂等交易回执。

## 接口

```bash
./trade buy 603228 \
  --name 景旺电子 --qty 1000 --price 76.46 \
  --id 20260805-603228-buy-0956
```

`--id`可选；同一ID重复执行直接返回既有结果，不重复增加数量。`--dry-run`只输出预览。

## 一致性与失败处理

交易服务持有本地文件锁，在内存中计算全部新内容，再为每个目标写同目录临时文件。所有临时文件就绪后依次原子替换；任一步失败时恢复已替换文件。损坏的JSON会终止操作，不会当成空持仓覆盖。数量、成本和台账全程留在本机，不调用行情源。

## 测试

- 新标的一次同步所有目标；
- 已有标的按数量加权平均成本；
- 同一交易ID幂等；
- ID冲突拒绝；
- `--dry-run`不修改目标；
- 模拟中途替换失败，所有目标恢复原状。
