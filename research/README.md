# research/ —— 复盘研究知识库

AI 复盘产出的研究报告归档处。报告基于公开行情数据，随仓库版本管理；每份自带数据窗口、复现命令与方法论备忘，供后续回顾与 AI 读取。

- 原始日K数据：`data/drop_study_*.json`（本地生成，gitignored，随时可用 `tools/drop_study.py` 重建）。
- `交易台账.md`：个人持仓与决策记录，**只存本地、不进仓库**（.gitignore 已排除）；实时盈亏看 App「持仓」页。
